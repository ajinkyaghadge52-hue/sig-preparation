# SIG Interview Preparation

Dedicated preparation workspace for the SIG/Susquehanna Quantitative Data Operations Engineer interview.

## Study method

Understand -> Predict -> Run -> Inspect -> Fix -> Explain -> Record

- Learn one small concept at a time.
- Attempt every exercise before viewing a completed answer.
- Explain errors in simple language.
- Update `PROGRESS.md` after every completed section.

## Contents

- `linux/` - navigation, files, logs, processes, resources, and permissions
- `python/` - foundational functions and debugging
- `pandas/` - data loading, exploration, filtering, and aggregation
- `data/` - small practice datasets and logs
- `.codex_notes/` - plan, summary, and learning notes
