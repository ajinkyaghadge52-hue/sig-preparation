# SIG Interview Preparation Plan

## Phase 1: Linux fundamentals

- [x] Navigation: `pwd`, `ls`, `ls -la`, `cd`, `cd ..`, `cd ~`
- [x] File operations: `mkdir`, `touch`, `cp`, `mv`, `rm`
- [x] Find CSV files recursively
- [ ] Read and search logs: `cat`, `less`, `head`, `tail`, `grep`, `wc`
- [ ] Combine commands: `|`, `>`, `>>`
- [ ] Inspect processes and resources
- [ ] Understand basic permissions
- [ ] Complete a conversational Linux drill

## Phase 2: Python refresh

- [ ] Trace a short function by hand
- [ ] Solve counting and filtering functions without copying
- [ ] Practise dictionaries, sets, sorting, and slicing
- [ ] Explain and fix common errors
- [ ] Complete one timed foundational function

## Phase 3: Pandas workflow

- [ ] Load a CSV safely
- [ ] Inspect shape, columns, types, missing values, and sample rows
- [ ] Filter and sort data
- [ ] Group and aggregate data
- [ ] Explain findings clearly
- [ ] Complete a timed analysis drill

## Phase 4: Interview simulation

- [ ] Complete a 60-minute mock
- [ ] Review the mistake bank
- [ ] Prepare a concise open-book cheat sheet
